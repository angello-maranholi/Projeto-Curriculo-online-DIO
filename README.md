
# Projeto Currículo Online - DIO

Página de currículo profissional desenvolvida como projeto acadêmico final do curso JavaScript Developer proposto pela DIO. 

## Objetivo

Utilizar skills de HTML, CSS e JavaScript na construção de uma página que reúne minhas informações profissionais, habilidades, experiências, formação acadêmica e contatos.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Estrutura e funcionamento

O projeto organiza as informações em uma página de currículo dividida em seções, com foco na apresentação do perfil profissional e na facilidade de navegação.

O **HTML** define a estrutura do currículo, incluindo cabeçalho com informações de contato, habilidades, portfólio, experiências profissionais, formação acadêmica, idiomas e redes sociais.

O **CSS** é responsável pela identidade visual e pela organização do layout. Os estilos foram separados em arquivos específicos, facilitando a manutenção e os ajustes de cada parte da página, incluindo a responsividade.

O **JavaScript** adiciona interatividade por meio de eventos de clique. Ao clicar no título de uma seção, o código alterna a classe `open` do elemento correspondente, permitindo expandir ou recolher seu conteúdo. Esse comportamento utiliza `addEventListener()` e `classList.toggle()`.

A organização dos arquivos separa a estrutura, a apresentação e o comportamento da aplicação, tornando o código mais fácil de entender e modificar.

## Como executar o projeto

Neste primeiro momento o projeto ainda não está hospedado, então será necessário clonar o repositório:

1. Clone o repositório.
2. Abra a pasta do projeto no VS Code.
3. Execute o arquivo `index.html` com a extensão Live Server.

## Diferenciais e aprendizados

- Aplicação prática da integração entre HTML, CSS e JavaScript.
- Organização de estilos em arquivos separados por responsabilidade.
- Manipulação do DOM e utilização de eventos para criar interações.
- Construção de seções expansíveis e recolhíveis com JavaScript.
- Aplicação de conceitos de responsividade e organização de recursos.
- Prática de versionamento e desenvolvimento de um projeto acadêmico com foco em apresentação profissional.
