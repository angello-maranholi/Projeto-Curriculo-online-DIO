
# Projeto Currículo Online - DIO

Página de currículo profissional desenvolvida como projeto acadêmico final do curso JavaScript Developer proposto pela DIO. 

## Objetivo - Estrutura e funcionamento

Utilizar skills de HTML, CSS e JavaScript na construção de uma página que reúne minhas informações profissionais, habilidades, experiências, formação acadêmica e contatos.
O projeto organiza as informações em uma página de currículo dividida em seções, com foco na apresentação do perfil profissional e na facilidade de navegação.
A organização dos arquivos separa a estrutura, a apresentação e o comportamento da aplicação, tornando o código mais fácil de entender e modificar.
Foi implementado o consumo de API do GitHub via Json, assim facilitará a atualização das informações do curriculo sem precisar modificar a dinamica no HTML a todo momento.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
